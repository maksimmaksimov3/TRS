OUR APPROACH
Phase 1 — Week 1
Audit & Discovery

Full review of existing visual identity assets, communication documents, and the meetMED website (meetmed.org). Establishes the baseline and identifies gaps in EU visibility compliance.

Requires: WordPress backend access, hosting & domain

Phase 2 — Weeks 2–4
Visual Identity & EU Compliance

Refinement of visual identity and production of guidelines — logo usage, colour palette, typography. PowerPoint and Word templates developed in parallel, integrating EU visibility requirements from the outset.

Phase 3 — Weeks 2–4
Website Alignment

Running in parallel with Phase 2. Frontend fixes, updated visual identity applied, EU compliance elements implemented on meetMED website (WordPress / Elementor). Modular scope: Options A, B, and C available.

Phase 4 — Final Week
Quality Check & Handover

Final QA across all deliverables, followed by handover of working files in open, editable formats. All deliverables targeted for completion before mid-April.

TECHNICAL SPECIFICATIONS
Platform

WordPress + Elementor (current setup). Elementor Pro licence required — client purchases or we purchase and transfer post-delivery. Elementor updated to latest stable version before design work begins.

Design Elements

Button styles, borders, and section gaps applied globally via Elementor theme style. Slider/carousel via Elementor-native widgets only. No custom JS. Custom CSS in Elementor CSS fields — no direct theme file edits.

Development

Mockups delivered in Figma (or equivalent) and approved before development. No child theme. No custom theme modifications.

Plugins

All plugins updated to latest stable versions (Option A). Unsupported / security-risk plugins removed. SEO via Yoast SEO (free). Events via existing Events Calendar plugin.

Excluded Scope

No WooCommerce, membership, or booking functionality. No third-party API integrations. No multisite or multilingual configuration. No server config, DNS management, or hosting migration.

Included in All Options

Final quality check across all deliverables. Handover of editable source files. No long-term social media management, campaigns, or full website redevelopment.
